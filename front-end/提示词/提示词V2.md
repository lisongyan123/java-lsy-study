# 角色：高级前端工程师（UI/UX 专家）
# 任务：生成一个支持卡片/表格双视图的 AgentSpec 与配置管理静态页面

## 1. 核心目标
创建一个生产级、单文件的纯静态 HTML 页面，用于展示“AgentSpec 列表”和“Nacos 配置列表”。页面必须支持在 **卡片视图** 与 **表格视图** 之间无缝切换。设计风格需保持企业级、干净、完全响应式，且严禁使用任何后端依赖。

## 2. 技术栈与强制约束
- **交付格式**：单个 `.html` 文件（HTML + CSS + JS 全部内联）。
- **样式方案**：仅允许使用 Tailwind CSS CDN (`<script src="https://cdn.tailwindcss.com"></script>`)。
- **图标规范**：仅允许使用内联 SVG。**严禁**引入任何外部图标库（如 FontAwesome、Material Icons 等）。
- **动画禁令**：**严格禁止**任何形式的 CSS 动画、过渡效果（transition）、关键帧（keyframes）。唯一允许的动态效果是 `hover:shadow-md`。
- **滚动条处理**：视觉上完全隐藏，但保留滚动功能。请使用 Tailwind 工具类：`[&::-webkit-scrollbar]:hidden [-ms-overflow-style:none] [scrollbar-width:none]`。
- **字体规范**：系统默认字体栈 (`-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`)。
- **设计语言**：“原角”美学。所有容器、按钮、输入框统一使用 `rounded-lg`；卡片组件使用 `rounded-xl`。全局背景色固定为 `#F7F9FC`。

## 3. 布局架构
实现左侧固定侧边栏 + 右侧自适应主内容区的两栏布局：
- **左侧侧边栏**：固定宽度 `w-64` (16rem)，高度撑满全屏，白色背景，右侧带边框。
- **右侧主内容区**：自适应剩余宽度，包含顶部控制栏 + 视图容器。
